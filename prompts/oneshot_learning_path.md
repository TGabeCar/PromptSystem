Use web search to create a **structured learning path**:

1. **Prerequisites** — what they should know first (if any)
2. **Ordered steps** — logical sequence, each with clear outcome
3. **Resources per step** — official docs, tutorials, courses (with URLs)
4. **Time estimates** — rough hours/days per step
5. **Hands-on checkpoints** — small projects or exercises to verify understanding
6. **Common pitfalls** — what trips people up, how to avoid
